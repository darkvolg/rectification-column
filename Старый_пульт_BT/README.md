# Колонна BT — старый пульт (Bluetooth + TempMeter + Home Assistant)

Две системы колонны — НЕ путать:

| | **Колонна BT** (эта папка) | **Колонна ESP** (весь остальной проект) |
|---|---|---|
| Плата | старая, `alcodistillersDSO`, Bluetooth | новая ESP32, 192.168.0.55, Wi-Fi |
| Где цифры | TempMeter на ноуте dark | свой пульт `web/`, прошивка `esphome/` |
| В HA | `sensor.kolonna_par`, `_par23`, `_voda`, `_kub`, `_davl` | `sensor.kolonna_t1_kub`, `_t2_carga`… (ESPHome) |
| Фраза | «продолжаем старый пульт» | «продолжаем колонну» |

## Цепочка

Плата → Bluetooth → **TempMeter** (`Desktop\колонна\tma1037.jar` на ноуте dark,
Tailscale 100.120.163.58) → лог `tmlog-*.log` → **kolonna_watch.ps1**
(на ноуте в `Desktop\колонна\уведомления`) → HA 192.168.0.74 → страница `/kolonna-pult`
+ голос Алисы.

## Файлы

- `kolonna_watch/` — скрипт на ноуте. Здесь эталон, на ноуте копия (+ `token.txt`).
  Файл `.ps1` обязательно в UTF-8 **с BOM** — PowerShell 5.1 иначе ломает кириллицу.
- `ha/make_dashboard_kolonna.py` — заливает страницу «Колонна». Перезаписывает её
  ЦЕЛИКОМ: ручные правки на странице сначала перенести сюда.
- `ha/kolonna_package.yaml` — пороги, кнопки, голос, сторож ноута
  (в HA: `/config/myconfig/packages/kolonna.yaml`).
- `ha/kolonna-fit.js` — страница сама ужимается под узкое окно рядом с TempMeter
  (в HA: `/config/www/`).

## Грабли

- **В HA «нет данных» у всех датчиков** → TempMeter не пишет лог (файл 0 байт).
  У каждого датчика в TempMeter нужна галочка «Журналировать Температуру»
  (окно датчика) + «Настройки → Начать Журналирование». С 2.4.0 скрипт сам
  подсказывает голосом.
- Прямая ровная линия на графике HA ≠ данные идут: график тянет последнее
  значение до «сейчас». Смотреть плитки справа (свежесть 2 мин).
- Две копии TempMeter одновременно — закрыть лишнюю (`javaw`).
- В сам TempMeter правки не вносим (чужая закрытая Java-программа) — всё новое
  делаем в скрипте или на странице HA.
