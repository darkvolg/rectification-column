# Копия дашборда Home Assistant перед правкой графика

Снято 12.09.2026, перед заменой карточки `history-graph` на `apexcharts-card`
во вкладке «Колонна» дашборда «Обзор».

| Файл | Что внутри |
|---|---|
| `kolonna_view.json` | только вкладка «Колонна» целиком |
| `lovelace_full.json` | весь дашборд «Обзор», все семь вкладок |

## Как откатить

Правится через веб-интерфейс: «Обзор» → три точки справа сверху →
«Правка дашборда» → снова три точки → «Редактор конфигурации»
(raw config editor). Туда вставляется содержимое `lovelace_full.json`,
переведённое в YAML, либо вручную возвращается карточка из
`kolonna_view.json`, путь `sections[1].cards[1]`.

Старая карточка была такой:

```yaml
type: history-graph
title: Температуры
hours_to_show: 12
refresh_interval: 10
entities:
  - entity: sensor.kolonna_t2_carga
    name: Царга 2/3
  - entity: sensor.kolonna_t3_otbor
    name: Отбор
  - entity: sensor.kolonna_t1_kub
    name: Куб
  - entity: sensor.kolonna_t4_voda
    name: Вода, выход
```

Все четыре датчика лежали на ОДНОЙ оси, хотя куб идёт с 20 до 98 °C,
царга с отбором держатся около 78, а вода около 30. Из-за этого шкала
всегда была растянута по самому размашистому каналу, а разница между
царгой и отбором — те десятые доли, по которым ловят фронт, —
схлопывалась в одну линию. Ради этого карточка и заменена на две.
