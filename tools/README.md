# Логирование погона

## Правило, из которого всё следует

**Журнал должен вести то устройство, которое включено весь погон.**
Это контроллер: он же и меряет, и без него колонна не работает. Ноут уснёт,
браузер закроют, сервер есть не у каждого. Поэтому логирование живёт
в ESP32, а всё остальное — необязательные надстройки.

Так проект остаётся переносимым: другой человек прошил плату, открыл
страницу — и у него уже пишется журнал. Ни сервера, ни Home Assistant,
ни Python.

## Три уровня, от обязательного к необязательному

| Уровень | Что нужно | Глубина | Переживает |
|---|---|---|---|
| **1. Журнал в контроллере** | ничего, есть в прошивке 0.5.0 | 11 часов | закрытый браузер, отсутствие сети наружу |
| **2. microSD в контроллере** | модуль с картой ~250 ₽ | без предела | перезагрузку, обесточивание |
| **3. Home Assistant** | HA в доме | месяцы, графики и аналитика | всё |

Уровень 1 закрывает погон. Уровни 2 и 3 — про архив за годы.

---

## Уровень 1. Журнал внутри ESP32

Работает сразу после прошивки. Пишет строку раз в 20 секунд:
все температуры, ΔT, скорость роста 2/3, расчётный спирт в кубе, обе
мощности, ток, напряжение, проток, расход воды, давление, отбор
и **состояние каждой аварии**.

### Как забрать

```
http://192.168.0.55/log.csv
```

Отдаётся готовым CSV: разделитель `;`, BOM, десятичная запятая —
русский Excel открывает двойным щелчком, без мастера импорта.
Имя файла с датой, два погона друг друга не затрут.

На странице «Графики» есть кнопка **«Журнал контроллера»** — она ведёт туда же
и показывает, сколько записей уже накоплено. Рядом кнопка «История браузера» —
это другое, см. ниже.

Скачать можно с чего угодно: с ноута, с телефона, из другой комнаты.
Контроллер отдаёт файл сам, страница для этого не нужна.

### Перед новым погоном

Нажать **Reset Log** (кнопка есть в Home Assistant и на странице самого
контроллера `http://<ip>/`). Иначе в файле окажется хвост прошлого погона,
и его потом примут за начало этого.

### Чего этот уровень не умеет — без карты

**Без microSD журнал живёт в оперативной памяти, и перезагрузка его стирает.**
Пропало питание, нажал Restart, прошил заново — журнал пуст.

80 КБ во внутренней памяти — всё, что можно взять без железа. Во время
погона контроллер не перезагружается, так что на практике мешает редко,
но ради этого и ставится карта из уровня 2.

Ещё: глубина 11 часов кольцом. Двенадцатый час затрёт первый.

## Уровень 2. microSD — вечный журнал

Модуль microSD-SPI (~250 ₽ с картой) на свободные пины:

| Модуль | ESP32 |
|---|---|
| CS | GPIO5 |
| SCK | GPIO14 |
| MOSI | GPIO13 |
| MISO | GPIO27 |
| VCC | 5 В (у модулей со стабилизатором) или 3.3 В |

Карта вставлена — журнал пишется файлом на неё, и перезагрузка не страшна.
Файл на каждый погон, имя с датой. Список: `http://<ip>/logs`,
скачать любой: `/logs/<имя>`. Карту можно просто вынуть и вставить
в компьютер.

Карты нет или её выдернули — прибор не встаёт, журнал продолжает писаться
в память. Это видно в диагностике: сущность **SD Card** покажет проблему,
а **Log Rows SD** замрёт на нуле.

Карту воткнули посреди погона — контроллер это заметит и **сольёт в файл
всё, что уже накопилось в памяти**. Начало погона не теряется.

---

## Уровень 3. Home Assistant

Если HA в доме есть, он пишет все сущности ESPHome сам, без единой строчки
кода: компонент `recorder`, база SQLite, глубина месяцами. Плюс графики,
уведомления в телефон, доступ снаружи.

Настройка — в `../ha/README.md`.

---

## История в браузере — это не логирование

На странице пульта копится своя история: 12 часов, шаг 30 секунд.
Она нужна **только чтобы графики не начинались с нуля** при переходе
между страницами.

Она пишется, пока вкладка открыта, и живёт в этом браузере на этом
устройстве. Закрыл вкладку — дыра. Открыл с телефона — там своя, пустая.
Для журнала погона это не годится, и кнопка «История браузера» подписана
именно так, чтобы не перепутать.

---

## Смотреть издалека

Журнал и страница живут в домашней сети. Чтобы открывать их с улицы
или из другого города, нужен доступ в домашнюю сеть — **Tailscale**
(в этом хозяйстве уже развёрнут, см. проект «Удалённый рабочий стол»).
Поставил на телефон, вошёл — и `http://192.168.0.55/log.csv` открывается
откуда угодно, как из дома.

Так безопаснее, чем пробрасывать порт наружу: ESPHome web_server
не рассчитан на открытый интернет — там нет ни пароля, ни шифрования.
**Не выставляй контроллер в интернет напрямую.**

## logger.py — запасной вариант

Скрипт на Python, который пишет тот же CSV с компьютера, подключаясь
к контроллеру напрямую.

```bash
python logger.py 192.168.0.55 --step 10 --dir D:\Погоны
```

Он не нужен, когда работает журнал в контроллере. Пригодится, если:

* хочется шаг чаще 20 секунд;
* нужен непрерывный лог длиннее 11 часов без риска потерять кольцо;
* хочется писать сразу на компьютер, минуя скачивание.

Зависимостей нет, только стандартный Python 3. При обрыве связи пишет
строку `НЕТ СВЯЗИ` вместо повтора последнего значения: **пропуск должен
быть виден.** Подделанные данные хуже отсутствующих — по ним делают выводы.

## Журнал ректификации — страница «Журнал»

Это другое, чем лог по секундам. Страница повторяет бумажный журнал:
шапка «сырьё и условия», расчёт фракций от абсолютного спирта, таблица
по времени с фазами.

Что прибор подставляет сам при записи строки: температуры, напряжение,
скорость отбора. Что вписываешь ты: фазу, объём отбора при ручном замере,
примечание. Строка добавляется кнопкой или сама раз в N минут.

Кнопка «Скачать журнал» отдаёт CSV с шапкой и расчётом — открывается
в Excel двойным щелчком.

### Excel делает сама страница

Кнопка **«Скачать Excel»** отдаёт готовый .xlsx — никакого Python
и никаких установок. Внутри всё как в бумажном журнале: шапка с сырьём,
блок фракций **живыми формулами** (поменял крепость в ячейке —
пересчиталось всё, включая ΔT в таблице), заливка строк по фазам,
закреплённая шапка, автофильтр, итоговая строка отбора.

Генератор `xlsx.js` лежит рядом со страницей и работает без интернета:
у колонны его может не быть, а библиотеку с CDN тогда не подтянуть.

Кнопка «CSV» рядом — когда нужен простой текстовый файл.

### csv2xlsx.py — когда нужен лог контроллера вторым листом

```bash
pip install openpyxl
python csv2xlsx.py журнал.csv --log log.csv -o Погон_01.xlsx
```

Это единственное, чего страница не умеет: подшить к журналу
многотысячный лог по секундам. Для обычного погона он не нужен.

## Проверка перед первым погоном

1. Открыть `http://<ip>/log.csv` — должен скачаться файл с заголовками.
2. Подождать минуту, скачать ещё раз — строк стало больше.
3. Открыть в Excel: колонки разъехались по ячейкам, запятая десятичная,
   русские заголовки читаются.
4. Нажать Reset Log, скачать снова — файл пустой, только заголовки.

Если пусто с самого начала — контроллер не знает времени (нет ни HA,
ни интернета для SNTP) либо прошивка старее 0.5.0. Время в первой колонке
покажет `без времени`, но данные всё равно пишутся.
